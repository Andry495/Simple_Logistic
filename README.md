# Simple Logistic - Wi-Fi Positioning System

Android приложение для определения местоположения устройства на карте предприятия с использованием Wi-Fi Positioning System (WPS) на основе триангуляции по точкам доступа.

## Возможности

- 📡 **Wi-Fi сканирование**: Автоматическое обнаружение точек доступа и получение силы сигнала (RSSI)
- 📍 **Триангуляция**: Определение местоположения устройства по силе сигналов от нескольких точек доступа
- 🗺️ **Интерактивная карта**: Перетаскивание точек доступа на плане предприятия для их позиционирования
- 🎓 **Обучение системы**: Автоматическая корректировка позиций точек доступа на основе измерений
- 📏 **Калибровка масштаба**: Настройка масштаба карты по двум известным точкам
- 💾 **Сохранение данных**: Сохранение позиций точек доступа между сеансами

## Технологии

- **Kotlin** - язык программирования
- **Android SDK** - платформа разработки
- **Wi-Fi RSSI** - определение силы сигнала для позиционирования
- **Триангуляция** - математический алгоритм определения координат

## Требования

- Android 9.0 (API 28) или выше
- Разрешения:
  - `ACCESS_FINE_LOCATION`
  - `ACCESS_WIFI_STATE`
  - `CHANGE_WIFI_STATE`
  - `NEARBY_WIFI_DEVICES` (Android 13+)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Andry495/Simple_Logistic.git
```

2. Откройте проект в Android Studio

3. Синхронизируйте Gradle зависимости

4. Соберите и запустите приложение на устройстве или эмуляторе

## Использование

1. **Разрешения**: При первом запуске предоставьте необходимые разрешения
2. **Калибровка**: Нажмите "Calibrate" и укажите две точки на плане, затем введите реальное расстояние между ними
3. **Позиционирование точек доступа**: При первом сканировании точки будут автоматически размещены по кругу. Перетащите их на правильные места на плане
4. **Определение местоположения**: Нажмите "Scan Wi‑Fi" для определения вашего местоположения. Позиция отобразится голубой точкой на карте

## Алгоритм работы

1. Сканирование Wi-Fi сетей и получение RSSI (силы сигнала) каждой точки доступа
2. Преобразование RSSI в расстояние с использованием модели затухания сигнала (Path Loss Model)
3. Триангуляция: вычисление координат устройства на основе расстояний до минимум 3 точек доступа
4. Обучение: автоматическая корректировка позиций точек доступа для повышения точности
